## 续费流程：账单什么时候来，提前续费怎么操作

RackNerd 的续费是账单制：到期前 14 天系统自动生成发票并发邮件通知，你手动付款，付完自动延长一个周期。等不及系统提醒的，也可以在后台手动生成账单提前续。

### 到期前的自动提醒

到期前 14 天生成续费发票并发邮件。一个实际建议：这类提醒邮件偶尔会进垃圾箱，把 RackNerd 的发件域名加进白名单，比事后翻垃圾箱靠谱得多。

### 提前续费的 5 步操作

提前续费主要防两件事：忘了付、机器被回收。操作全程在客户后台完成：

1. 登录 RackNerd 客户后台，进入 Services → My Services
2. 在服务列表里点开要续费的那台 VPS
3. 左侧 Actions 区域找到 Generate Renewal Invoice，点一下
4. 系统生成下一个周期的账单，去 Billing → My Invoices 里点开 Unpaid 状态的账单核对明细
5. 完成支付，续费立即生效

两个容易误解的点。一是提前续费不会“浪费”剩余天数：新周期从原到期日往后叠加，你本月 20 号到期，今天提前续，下个周期还是从 20 号开始算。二是后台一次只能生成一个周期的账单，想一口气锁几年，就连续操作几次，每付一次到期日往后推一年——不过对本身就不涨价的商家，连续锁几年的意义主要是图省事，价格上没有额外收益。

### 到期没续会怎样

不会立刻删机器。到期后有几天宽限期，期间补缴账单就能恢复；拖太久数据可能被清掉。所以别赌宽限期，看到邮件就去付。

## 关于续费的常见疑问

**RackNerd 续费同价是真的吗？**

真的。定价是 recurring 模式，首年价即续费价，官方知识库有明文，限量套餐同样适用，长期用户的续费反馈也印证了这一点。

**续费时配置会缩水吗？**

不会。续费只延长时间，CPU、内存、存储、流量都保持原样。

**套餐下架了还能按原价续吗？**

能。已购用户的续费权一直保留，只要按时续费，下架套餐照样按买入价续——这也是黑五、新年限量套餐“抢到就是赚到”的原因。

**能不能一次锁好几年的价？**

后台一次只能续一个周期，连续提前续可以往后叠加多个周期。但 RackNerd 本身续费不涨价，锁多年价没有价格上的收益，主要意义是防止忘续。

**流量用超了会怎么处理？**

一般会限速或临时停机，不会自动扣费。套餐流量给得比较宽裕，6GB 档 10TB 往上，轻量用途很难跑满。

**提前续费会把没用完的时间覆盖掉吗？**

不会，新周期从原到期日开始叠加，剩余天数照算。
